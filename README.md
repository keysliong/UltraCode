# UltraCode

ИИ-агент для программирования прямо на Android-телефоне. Material You, кнопки в форме «печенек» (cookie shapes).

## Возможности
- **Чат с ИИ** со стримингом ответов, Markdown и подсветкой блоков кода
- **Claude** (вход по API-ключу из console.anthropic.com)
- **Бесплатные модели** через OpenRouter: DeepSeek, GLM, Qwen Coder, Kimi, Llama, Gemma… (список обновляется кнопкой)
- **Свои нейросети**: любой OpenAI- или Anthropic-совместимый API (DeepSeek, GLM/Zhipu, Groq, Gemini, Mistral, Ollama, LM Studio, Pollinations)
- **Режим агента**: ИИ сам создаёт и редактирует файлы в выбранной папке телефона
- **GitHub**: подключение по токену, список репозиториев, создание репозиториев, коммиты, скачивание, статус и логи GitHub Actions
- **Сборка приложений для телефона и ПК**: агент пишет проект + workflow, пушит на GitHub, Actions собирает APK/EXE, агент читает логи и чинит ошибки
- **«Агент хочет спросить»**: уведомление и карточка с вопросом, когда ИИ нужен ваш ответ
- **История чатов**, загрузка фото, копирование и «поделиться» ответом, видно, какая модель ответила
- **Настройки**: Material You / тема, ключи, свои инструкции, лимит шагов агента, папка проектов

## Сборка
APK собирается автоматически GitHub Actions при каждом push (`.github/workflows/build.yml`)
и публикуется в разделе **Releases** (файл `UltraCode.apk`).

Локально: `./gradlew :app:assembleRelease` (нужен Android SDK 35).

> `app/ultracode.jks` — ключ подписи этого приложения (пароль `ultracode`), чтобы обновления ставились поверх. Для публикации в магазине замените его на свой и храните в секретах.
