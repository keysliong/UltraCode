Возможности

Всё для работы с ИИ в одном приложении

Бесплатные модели

DeepSeek, GLM, Qwen Coder, Kimi, GPT-OSS через OpenRouter и Groq. Перегруженная модель заменяется сама.

Claude Code по подписке

Официальный Claude Code внутри приложения. Вход в свой аккаунт Claude Pro или Max.

Агент и GitHub

Создаёт репозитории, пишет код, публикует сайты на GitHub Pages и собирает APK и EXE через Actions.

Python и терминал

Кнопка «Запустить» под кодом и встроенный терминал: python, pip install.

Сайты прямо в чате

HTML из ответа открывается в окне предпросмотра. Видно, какие сайты читала нейросеть.

Свои нейросети

Любой API в формате OpenAI или Anthropic: DeepSeek, Gemini, Mistral, Ollama на своём ПК.

Установка на Android

Три шага до первого запуска

  1. Скачайте APK

    Нажмите «Скачать APK». Файл UltraCode.apk сохранится в «Загрузки».

  2. Разрешите установку

    Откройте файл. Если телефон спросит, разрешите установку из этого источника.

  3. Подключите модели

    В настройках вставьте бесплатный ключ OpenRouter или Groq, или войдите в Claude.
